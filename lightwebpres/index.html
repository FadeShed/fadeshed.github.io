01 / ONE SOURCE, SEVERAL CONTEXTS

Not a slide export.
A publishable document.

Generated articles carry their CSS and JavaScript. Readers need a browser, not LightWebPres, an account, or a presentation service. Portrait favors reading; landscape adds presentation navigation without changing the source.

READ

Scrollable when it needs to be

Long content stays readable instead of being cut down just to fit a fixed slide frame.

PRESENT

Controls are built in

Keyboard, mouse and touch navigation, fullscreen, pause screens, slide counters, notes and printing are part of the generated page.

PUBLISH

Static by default

A series index and cross-article links are derived at build time. The result can live on ordinary static hosting.

02 / MADE TO BE AUTOMATED

Markdown stays
the source of truth.

People, scripts and agents can edit the same plain-text sources. The CLI is unattended, returns exit codes and ships with a format skill that makes the article grammar explicit.

CLI PIPELINE

Build, audit, verify.

The tool is small enough to drop into an automated workflow without introducing an application server.

python3 lightwebpres build my-series --lang en python3 lightwebpres audit my-series --strict python3 lightwebpres verify my-series
BROWSER BUILDER

The same engine, inside a tab.

The included browser builder runs the Python executable under Pyodide. It can build a series ZIP or synchronize with GitLab. It is a browser surface for the engine, not a second renderer.

Separate project: lightwebpres-gui is a distinct editor. It should not be conflated with the CLI or the browser builder.

03 / APPEARANCE WITH STRUCTURE

Identity, preset,
theme.

Those are separate concepts. Native layouts and Commons coexist with self-contained Identity Kits that can ship their own layouts, chrome, themes and assets.

Typed configuration

Repeatable rather than fragile.

Properties in settings.conf are typed and checked. Invalid names and values fail the build. Advanced custom.css remains available when you deliberately need to leave the checked surface.

Explore appearance and kits →

Trusted sources in, trusted HTML out.

LightWebPres is a renderer, not an HTML sanitizer. Raw HTML and scripts can pass through. Speaker notes are embedded in the generated page, and tags are viewing filters rather than access control. Sanitize untrusted input upstream and inspect what you publish.

GET STARTED

Python in.
Static HTML out.

The CLI needs Python 3.8+ and no extra packages. The repository guide is the operational manual; this site is the product overview.
