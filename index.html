Practical software built around the places where humans, agents, terminals, browsers and filesystems actually meet.

Most things in the shed started as a tool I needed myself. I publish them because so much of the software I rely on exists only because another developer chose to share. This is my small way of returning the favor to developers, sysadmins, tinkerers, and fellow nerds.

“Build the thing that removes friction. Keep it understandable. Leave the door open for the next person with the same problem.”

FadeShed is not a company or a grand product suite. It is a home for practical software: small tools, odd utilities, experiments that survived contact with reality, and projects that became useful enough to clean up and share.

The common thread is increasingly agentic computing: software that gives agents useful surfaces, lets them exchange artifacts with people and tools, or makes their output easier to inspect, publish and reuse.

Projects are allowed to finish. If the ecosystem eventually makes one unnecessary, it can retire without turning into an obligation.

The shed rule

Practical beats impressive.

No roadmap theatre. No need to turn every useful script into a startup. If a tool solves a real problem, can be explained clearly, and might help someone else, it belongs here.
